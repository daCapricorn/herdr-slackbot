# Herdr Bridge 사용 가이드

[English](GUIDE.md) | **한국어**

현재 설치·설정·명령·마이그레이션 설명은 [영문 사용 가이드](GUIDE.md)를 참고하세요. Bridge는 OpenClaw Gateway가 관리하며 Slack 인증은 OpenClaw가 담당합니다.

이전 Slack 앱 생성, `.env` token 설정, 페어링, Home 탭과 스레드 답장 절차는 [보관된 가이드](../legacy/docs/GUIDE.ko.md)로 이동했습니다. 새로운 Bridge 설치에 해당 절차를 사용하지 마세요.
